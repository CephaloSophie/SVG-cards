Figures de belote

Valet, dame et roi des quatre couleurs ♠︎♥︎♦︎♣︎ : douze figures détourées, sans cadre, sans indice ni enseigne, sur fond transparent. Chaque figure existe en PNG et en base64, en quatre qualités. Le bouton Copier placé sous une figure copie son base64 dans la qualité choisie.

Les JSON ne sont pas encore chargés. Ouverte directement depuis le disque (adresse file://), une page n'a pas le droit de lire les fichiers voisins : les PNG s'affichent, mais le base64 reste dans les JSON. Chargez-les ici, ou servez le dossier avec python3 -m http.server puis ouvrez http://localhost:8000/.

Dans le code

Un fichier JSON par figure, dans json/. Il porte l'identité de la carte et, pour chaque qualité, les dimensions, le poids et le PNG encodé en base64. json/index.json liste les douze figures sans le base64.

const carte = await (await fetch("json/roi-pique.json")).json();

carte.id                      // "KS"
carte.name                    // "Roi de Pique"
carte.qualities.high.width    // 672
carte.qualities.high.base64   // "iVBORw0KGgo…"

img.src = carte.data_uri_prefix + carte.qualities.high.base64;
